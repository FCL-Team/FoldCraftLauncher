Fold Craft Launcher プライバシーポリシー

バージョン：2
最終更新日：2026年10月23日

Fold Craft Launcher（以下「FCL」）は、FCL-Team が開発した Minecraft: Java Edition 用のオープンソースランチャーです。私たちはお客様のプライバシーを大切にしています。本ポリシーでは、FCL がどのような情報を処理するのか、その理由、情報の送信先、および情報の管理方法について説明します。FCL をご利用になる前に、よくお読みください。

1. 概要

(1) FCL にはアカウント制度がありません。FCL-Team がお客様の個人情報を販売または貸与することはありません。
(2) FCL には、分析、広告、プッシュ通知などのサードパーティ SDK は一切組み込まれていません。
(3) ほとんどのデータはお客様のデバイス内にのみ保存されます。オンライン機能を利用するときに限り、お客様のデバイスが該当するサービスに直接接続し、そのサービスは IP アドレスなどのネットワークリクエスト情報を受け取ります。
(4) お客様が本ポリシーと利用規約に同意するまで、FCL は権限を要求せず、インターネットにも接続しません。

2. デバイスに保存される情報

FCL は次の情報をお客様のデバイス上で処理し、保存します。FCL-Team がこれらにアクセスすることはできません。

(1) アカウント情報：オフラインアカウントのユーザー名と UUID、Microsoft アカウントおよび外部認証アカウントのユーザー名、UUID、スキン情報、ログイン認証情報（アクセストークンやリフレッシュトークンなど）。アカウント情報は FCL のアプリ専用の非公開ストレージに保存され、該当するサービスへのログインとゲームの起動にのみ使用されます。
(2) ゲームデータ：ゲームのバージョン、Mod、Modpack、リソースパック、シェーダーパック、ワールド、スクリーンショット、操作レイアウトなどのファイル。これらは共有ストレージ上の FCL フォルダ、または FCL のアプリ固有ストレージに保存されます。共有ストレージ上のファイルには、ファイルマネージャーやストレージ権限を持つほかのアプリがアクセスできる場合があります。
(3) 設定：ランチャーの設定、ゲームの設定、お気に入り、ダウンロード履歴など。
(4) ログとクラッシュレポート：ランチャーのログ、ゲームのログ、マルチプレイのログ、クラッシュレポート。これらには、デバイスのブランドとモデル、システムのバージョン、プロセッサ・グラフィックス・メモリの情報、ファイルパス、ゲーム内のプレイヤー名が含まれる場合があります。ログは共有ストレージ上の FCL フォルダに保存され、お客様自身が共有またはアップロードしない限り、デバイスの外に出ることはありません。

3. オンライン機能とサードパーティサービス

次の機能を利用すると、お客様のデバイスは該当するサービスに直接接続します。これらのサービスは、お客様の IP アドレスと、リクエストの処理に必要な内容（要求されたファイルや検索キーワードなど）を受け取ります。一部のリクエストには FCL のバージョンも含まれます。これらのサービスはサードパーティまたはほかのオープンソースプロジェクトが運営しており、それぞれのプライバシーポリシーに従って情報を取り扱います。FCL-Team はこれらを管理できません。

(1) アップデートの確認とお知らせ：FCL は GitHub から、表示言語が中国語の場合は Gitee から、バージョン情報とランチャーのお知らせを自動的に取得します。
(2) ゲームと Mod ローダーのダウンロード：ゲーム本体、アセット、ライブラリ、Mod ローダーをダウンロードする際、FCL は選択したダウンロードソースに応じて、Mojang と Microsoft の公式サーバー、BMCLAPI ミラー、および Forge、NeoForge、Fabric、Quilt、LiteLoader、OptiFine、Cleanroom とその依存リポジトリのサーバーまたはミラー（HMCL が提供するメタデータサービスを含む）に接続します。
(3) コンテンツの検索とダウンロード：Mod、Modpack、リソースパック、シェーダーパック、ワールドを検索、閲覧、ダウンロードする際、FCL は CurseForge、Modrinth またはそのミラーである MCIM に接続し、コンテンツのアイコンとスクリーンショットを読み込みます。リクエストには検索キーワードと絞り込み条件が含まれます。
(4) アカウントへのログイン：Microsoft アカウントの場合、FCL は Microsoft のログインページで認証を行った後、Xbox Live と Minecraft のサービスに接続して、ゲームプロフィールとゲームの所有状況を取得します。ログイン後の応答を受け取るため、FCL はお客様のデバイスからのみアクセスできるサービスをデバイス上で一時的に起動します。外部認証アカウントの場合、FCL はお客様が追加した認証サーバーに接続し、authlib-injector コンポーネントをダウンロードします。
(5) スキン：スキンを表示、アップロード、変更する際、FCL は Mojang のスキンサービス、またはお客様が利用している外部認証サーバーに接続します。オフラインアカウントのスキンはデバイス内でのみ処理されます。
(6) 操作レイアウトのリポジトリ：操作レイアウトを閲覧、ダウンロードする際、FCL は GitHub またはミラーの repo.miawa.cn に接続します。
(7) ログのアップロード：お客様がログのアップロードを選択した場合に限り、FCL は選択したログを mclo.gs（表示言語が中国語の場合は logshare.cn）にアップロードし、リンクを生成します。リンクを知っている人は誰でもログを閲覧できます。アップロード前に FCL はログ内のゲームのアクセストークンを伏せますが、ログには 2. の (4) に挙げた情報が引き続き含まれる場合があります。
(8) Terracotta マルチプレイ：お客様がマルチプレイを有効にし、ゲーム内でルームを作成または参加した場合にのみ使用されます。FCL は Terracotta のノードリストを取得し、EasyTier を使って仮想ネットワークを構築します。セッション中、お客様のデバイスは、Terracotta のノード、EasyTier の公開ノード、および同じルーム内のほかのプレイヤーのデバイスと、ネットワークアドレスなどの接続に必要な情報を交換します。また、ルーム内のほかのプレイヤーにはお客様のプレイヤー名が表示されます。
(9) 地域の判定：FCL は、デバイスのタイムゾーンとシステムの地域設定のみから、デバイスが中国本土にある可能性を判断します（例：より近いダウンロードミラーを優先するため）。この判定は完全にお客様のデバイス上で行われ、FCL はそのために IP アドレスやネットワークサービスに問い合わせることはありません。
(10) ゲームの通信：ゲームの実行中、ゲームや Mod は、お客様が参加するサーバーへの接続など、独自にインターネットに接続します。これは FCL の管理外です。ゲームがドメイン名を解決できるように、FCL はゲーム用にシステムの DNS と公開 DNS を設定します。システムの言語が簡体字中国語（中国）の場合は AliDNS と DNSPod を、それ以外の場合は Cloudflare を使用します。ゲームが解決するドメイン名は、これらの DNS サービスに送信されます。
(11) 外部リンクとプロモーション：ドキュメント、コミュニティ、スポンサー、MC百科（mcmod.cn）、クラウドストレージなどへのリンクは、お客様がタップした後にのみ、ブラウザまたは対応するアプリで開かれます。デバイスの地域が中国本土で、中国語の画面を使用しているユーザーには、ゲームの起動前に Quark クラウドドライブのプロモーションが表示されることがあります。FCL がこれによってお客様の情報を第三者に提供することはありません。

4. 権限

(1) ストレージ：ゲームファイルの管理、Modpack や操作レイアウトのインポートとエクスポート、ログの保存のため、共有ストレージ上の FCL フォルダの読み書きを行います。
(2) ネットワークとネットワーク状態：上記のオンライン機能のため、および接続前にネットワークが利用可能かを確認するために使用します。
(3) 通知：ダウンロードの進行状況、ゲームの状態、マルチプレイの状態を表示します。
(4) フォアグラウンドサービス：バックグラウンドでのダウンロードの継続、ゲームプロセスの維持、マルチプレイ接続の維持に使用します。
(5) VPN：Terracotta マルチプレイの利用時にのみ要求し、マルチプレイに必要な仮想ネットワークを構築するために使用します。FCL がこの権限を使ってほかのアプリのネットワークデータを収集または改変することはありません。
(6) マイク：ランチャーの設定でお客様が自ら要求した場合にのみ付与され、ボイスチャット系 Mod など、マイクを必要とするゲーム内機能で使用されます。
(7) アプリのインストールとアンインストール：ダウンロードした FCL のアップデートのインストールと、FCL プラグインのアンインストールに使用します。
(8) インストール済みアプリの表示：FCL はデバイス上にインストールされている FCL プラグイン（レンダラー、ドライバー、FFmpeg プラグインなど）を探します。FCL はプラグインの識別に必要な情報のみを読み取り、アプリの一覧をアップロードすることはありません。
(9) バイブレーションとスリープの防止：タッチ操作のバイブレーションによるフィードバックと、ダウンロード中やゲーム中にデバイスがスリープしないようにするために使用します。

付与した権限はシステム設定からいつでも取り消すことができますが、関連する機能が動作しなくなる場合があります。

また、ゲーム内で貼り付けなどの操作を行うと、ゲームがクリップボードの内容を読み取る場合があります。FCL はその内容をゲームに渡すだけで、アップロードすることはありません。FCL は、IMEI、Android ID、MAC アドレス、広告 ID などのデバイス識別子を読み取りません。

5. 保存と安全管理

(1) お客様の情報はお客様のデバイスに保存され、保存期間はお客様が決めることができます。FCL をアンインストールするか、システム設定で FCL のデータを消去すると、アプリ専用の非公開ストレージ内のデータが削除されます。共有ストレージ上の FCL フォルダは、お客様ご自身で削除する必要があります。
(2) デバイスを適切に管理してください。ログ、Modpack、ゲームフォルダを共有する前に、公開したくない情報が含まれていないか確認してください。

6. お客様の権利

(1) FCL 内でアカウント、スキン、設定、ゲームファイルを確認、変更、削除できます。
(2) マルチプレイなどの任意の機能はいつでも無効にでき、権限はシステム設定で管理できます。
(3) 「設定 > アプリについて > プライバシーポリシー」から同意を撤回できます。撤回すると FCL はすぐに終了し、次に利用する前に改めて同意を求めます。同意を撤回しても、デバイス上のデータは自動的には削除されません。
(4) サードパーティのサービスが取り扱う情報については、それぞれのサービスのプライバシーポリシーに従って権利を行使してください。

7. 未成年の方へ

未成年の方は、保護者の方と一緒に本ポリシーをお読みいただき、保護者の方の同意を得たうえで FCL をご利用ください。

8. 本ポリシーの変更

本ポリシーは、FCL の機能の変更に応じて更新されることがあります。更新後、FCL は起動時に新しいバージョンを表示し、改めて同意を求めます。
