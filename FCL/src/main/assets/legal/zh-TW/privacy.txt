Fold Craft Launcher 隱私權政策

版本：2
更新日期：2026 年 10 月 23 日

Fold Craft Launcher（以下簡稱「FCL」）是由 FCL-Team 開發的開放原始碼 Minecraft Java 版啟動器。我們重視你的隱私。本政策說明 FCL 會處理哪些資訊、為什麼處理、這些資訊會傳送到哪裡，以及你可以如何管理它們。請在使用 FCL 前仔細閱讀。

一、概述

1. FCL 沒有帳號系統。FCL-Team 不會出售或出租你的個人資料。
2. FCL 沒有整合任何統計分析、廣告或推播類第三方 SDK。
3. 大部分資料只儲存在你的裝置上。只有在使用連網功能時，你的裝置才會直接連線到相應的服務，這些服務會收到你的 IP 位址等網路請求資訊。
4. 在你同意本政策和《使用者協議》之前，FCL 不會要求權限，也不會連網。

二、儲存在你裝置上的資訊

以下資訊由 FCL 在你的裝置上處理和儲存，FCL-Team 無法取得：

1. 帳號資訊：離線帳號的使用者名稱和 UUID；微軟帳號和外置登入帳號的使用者名稱、UUID、外觀資訊以及登入憑證（如存取權杖和重新整理權杖）。帳號資訊儲存在 FCL 的應用程式私有目錄中，只用於登入對應的服務和啟動遊戲。
2. 遊戲資料：遊戲版本、模組、整合包、資源包、光影包、存檔、截圖和控制佈局等。這些檔案儲存在共用儲存空間的 FCL 資料夾或 FCL 的應用程式專屬目錄中。共用儲存空間中的檔案可能被檔案管理工具或其他取得儲存權限的應用程式存取。
3. 設定：啟動器設定、遊戲設定、收藏和下載紀錄等。
4. 記錄檔和當機報告：啟動器記錄檔、遊戲記錄檔、連線記錄檔和當機報告，可能包含裝置品牌和型號、系統版本、處理器和顯示卡資訊、記憶體資訊、檔案路徑以及遊戲內的玩家名稱。記錄檔儲存在共用儲存空間的 FCL 資料夾中，除非你主動分享或上傳，否則不會離開你的裝置。

三、連網功能與第三方服務

使用以下功能時，你的裝置會直接連線到相應的服務。這些服務會收到你的 IP 位址和完成請求所需的內容（如請求的檔案、搜尋關鍵字），部分請求還會附帶 FCL 的版本號碼。這些服務由第三方或其他開放原始碼專案營運，會依照各自的隱私權政策處理資訊，FCL-Team 無法控制。

1. 更新檢查與公告：FCL 會自動從 GitHub 取得版本資訊和啟動器公告；介面語言為中文時改用 Gitee。
2. 遊戲與載入器下載：下載遊戲本體、資源檔案、相依函式庫和載入器時，FCL 會依你選擇的下載來源連線到 Mojang 和微軟的官方伺服器、BMCLAPI 鏡像，以及 Forge、NeoForge、Fabric、Quilt、LiteLoader、OptiFine、Cleanroom 等專案及其相依儲存庫的伺服器或鏡像（包括 HMCL 提供的中繼資料服務）。
3. 遊戲內容搜尋與下載：搜尋、瀏覽和下載模組、整合包、資源包、光影包和世界時，FCL 會連線到 CurseForge、Modrinth 或其鏡像 MCIM，並載入內容的圖示和截圖。請求會包含你的搜尋關鍵字和篩選條件。
4. 帳號登入：使用微軟帳號時，FCL 透過微軟的登入頁面完成授權，再連線到 Xbox Live 和 Minecraft 服務取得遊戲設定檔和遊戲擁有狀態。為接收登入回呼，FCL 會在本機暫時啟動一個僅供本機存取的服務。使用外置登入時，FCL 會連線到你新增的驗證伺服器，並下載 authlib-injector 元件。
5. 外觀：顯示、上傳或更換外觀時，FCL 會連線到 Mojang 的外觀服務或你使用的外置登入伺服器。離線帳號的外觀只在本機處理。
6. 控制佈局倉庫：瀏覽和下載控制佈局時，FCL 會連線到 GitHub 或中國大陸鏡像 repo.miawa.cn。
7. 記錄檔上傳：只有在你主動選擇上傳記錄檔時，FCL 才會把所選記錄檔上傳到 mclo.gs（介面語言為中文時為 logshare.cn），並產生一個連結。任何取得該連結的人都可以查看記錄檔內容。上傳前，FCL 會隱藏記錄檔中的遊戲存取權杖，但記錄檔仍可能包含第二節第 4 項所列的資訊。
8. 陶瓦聯機：只有在你開啟多人連線，並在遊戲內建立或加入房間時才會使用。FCL 會取得陶瓦聯機節點清單，並透過 EasyTier 建立虛擬網路。連線期間，你的裝置會與陶瓦聯機節點、EasyTier 公共節點以及同一房間內其他玩家的裝置交換網路位址等建立連線所需的資訊；房間內的其他玩家可以看到你的玩家名稱。
9. 地區偵測：FCL 僅根據裝置的時區和系統地區判斷裝置是否可能位於中國大陸，例如用於優先選擇較近的下載鏡像。該判斷完全在本機完成，FCL 不會因此查詢你的 IP 位址或任何網路服務。
10. 遊戲連網：遊戲執行時會依遊戲本身和模組的邏輯連網，例如連線到你加入的伺服器，這部分不受 FCL 控制。為了讓遊戲正常解析網域名稱，FCL 會為遊戲設定系統 DNS 和公用 DNS：系統語言為簡體中文（中國）時使用阿里雲公共 DNS 和 DNSPod，其他情況下使用 Cloudflare。遊戲需要解析的網域名稱會傳送給這些 DNS 服務。
11. 外部連結與推廣：文件、社群、贊助、MC 百科、雲端硬碟等連結只會在你點選後，由瀏覽器或對應的應用程式開啟。裝置地區為中國大陸且使用中文介面的使用者，在啟動遊戲前可能偶爾看到夸克網盤的推廣視窗。FCL 不會因此向任何第三方提供你的資訊。

四、權限

1. 儲存空間：讀寫共用儲存空間中的 FCL 資料夾，用於管理遊戲檔案、匯入匯出整合包和控制佈局，以及儲存記錄檔。
2. 網路和網路狀態：用於上述連網功能，以及在連網前檢查網路是否可用。
3. 通知：顯示下載進度、遊戲執行狀態和多人連線狀態。
4. 前景服務：在背景繼續下載、保持遊戲程序執行，以及維持多人連線。
5. VPN：只在使用陶瓦聯機時要求，用於建立連線所需的虛擬網路。FCL 不會利用此權限蒐集或修改其他應用程式的網路資料。
6. 麥克風：只有在你於啟動器設定中主動要求後才會取得，供遊戲內需要麥克風的功能使用，例如語音聊天類模組。
7. 安裝和解除安裝應用程式：用於安裝已下載的 FCL 更新，以及解除安裝 FCL 外掛程式。
8. 查看已安裝的應用程式：FCL 會在本機尋找已安裝的 FCL 外掛程式，例如渲染器、驅動程式和 FFmpeg 外掛程式。FCL 只讀取識別外掛程式所需的資訊，不會上傳應用程式清單。
9. 震動和防止休眠：用於觸控按鍵的震動回饋，以及在下載和遊戲期間防止裝置休眠。

你可以隨時在系統設定中撤銷已授予的權限，但相關功能可能因此無法使用。

此外，在你於遊戲中進行貼上等操作時，遊戲可能會讀取剪貼簿內容。FCL 只會把內容交給遊戲，不會上傳。FCL 不會讀取 IMEI、Android ID、MAC 位址或廣告 ID 等裝置識別碼。

五、資訊的儲存與安全

1. 你的資訊儲存在你的裝置上，由你決定保留多久。解除安裝 FCL 或在系統設定中清除 FCL 的資料，會刪除應用程式私有目錄中的資料；共用儲存空間中的 FCL 資料夾需要你手動刪除。
2. 請妥善保管你的裝置。分享記錄檔、整合包或遊戲目錄前，請檢查其中是否包含你不希望公開的資訊。

六、你的權利

1. 你可以在 FCL 中查看、修改和刪除帳號、外觀、設定和遊戲檔案。
2. 你可以隨時關閉多人連線等選用功能，並在系統設定中管理權限。
3. 你可以在「設定 > 關於 > 隱私權政策」中撤回同意。撤回後 FCL 會立即結束，再次使用前需要重新同意。撤回同意不會自動刪除你裝置上的資料。
4. 對於第三方服務處理的資訊，請依照對應服務的隱私權政策行使你的權利。

七、未成年人

如果你是未成年人，請在法定代理人的陪同下閱讀本政策，並在取得法定代理人同意後使用 FCL。

八、本政策的更新

本政策可能會隨 FCL 功能的變化而更新。更新後，FCL 會在啟動時顯示新版本，並再次徵求你的同意。
