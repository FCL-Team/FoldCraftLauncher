Fold Craft Launcher 隐私政策

版本：2
更新日期：2026 年 10 月 23 日

Fold Craft Launcher（以下简称“FCL”）是由 FCL-Team 开发的开源 Minecraft Java 版启动器。我们重视你的隐私。本政策说明 FCL 会处理哪些信息、为什么处理、这些信息会发送到哪里，以及你可以如何管理它们。请在使用 FCL 前仔细阅读。

一、概述

1. FCL 没有账号体系。FCL-Team 不会出售或出租你的个人信息。
2. FCL 没有集成任何统计分析、广告或推送类第三方 SDK。
3. 大部分数据只保存在你的设备上。只有在使用联网功能时，你的设备才会直接连接相应的服务，这些服务会收到你的 IP 地址等网络请求信息。
4. 在你同意本政策和《用户协议》之前，FCL 不会申请权限，也不会联网。

二、保存在你设备上的信息

以下信息由 FCL 在你的设备上处理和保存，FCL-Team 无法获取：

1. 账户信息：离线账户的用户名和 UUID；微软账户和外置登录账户的用户名、UUID、皮肤信息以及登录凭据（如访问令牌和刷新令牌）。账户信息保存在 FCL 的应用私有目录中，只用于登录对应的服务和启动游戏。
2. 游戏数据：游戏版本、模组、整合包、资源包、光影包、存档、截图和控制布局等。这些文件保存在共享存储的 FCL 文件夹或 FCL 的应用专属目录中。共享存储中的文件可能被文件管理器或其他获得存储权限的应用访问。
3. 设置：启动器设置、游戏设置、收藏和下载记录等。
4. 日志和崩溃报告：启动器日志、游戏日志、联机日志和崩溃报告，可能包含设备品牌和型号、系统版本、处理器和显卡信息、内存信息、文件路径以及游戏内的玩家名。日志保存在共享存储的 FCL 文件夹中，除非你主动分享或上传，否则不会离开你的设备。

三、联网功能与第三方服务

使用以下功能时，你的设备会直接连接相应的服务。这些服务会收到你的 IP 地址和完成请求所需的内容（如请求的文件、搜索关键词），部分请求还会附带 FCL 的版本号。这些服务由第三方或其他开源项目运营，会按照各自的隐私政策处理信息，FCL-Team 无法控制。

1. 更新检查与公告：FCL 会自动从 GitHub 获取版本信息和启动器公告；界面语言为中文时改用 Gitee。
2. 游戏与加载器下载：下载游戏本体、资源文件、依赖库和加载器时，FCL 会按你选择的下载源连接 Mojang 和微软的官方服务器、BMCLAPI 镜像，以及 Forge、NeoForge、Fabric、Quilt、LiteLoader、OptiFine、Cleanroom 等项目及其依赖仓库的服务器或镜像（包括 HMCL 提供的元数据服务）。
3. 游戏内容搜索与下载：搜索、浏览和下载模组、整合包、资源包、光影包和世界时，FCL 会连接 CurseForge、Modrinth 或其镜像 MCIM，并加载内容的图标和截图。请求会包含你的搜索关键词和筛选条件。
4. 账户登录：使用微软账户时，FCL 通过微软的登录页面完成授权，再连接 Xbox Live 和 Minecraft 服务获取游戏档案和游戏拥有情况。为接收登录回调，FCL 会在本机临时开启一个只供本机访问的服务。使用外置登录时，FCL 会连接你添加的认证服务器，并下载 authlib-injector 组件。
5. 皮肤：显示、上传或更换皮肤时，FCL 会连接 Mojang 的皮肤服务或你使用的外置登录服务器。离线账户的皮肤只在本机处理。
6. 控制布局仓库：浏览和下载控制布局时，FCL 会连接 GitHub 或国内镜像 repo.miawa.cn。
7. 日志上传：只有在你主动选择上传日志时，FCL 才会把所选日志上传到 mclo.gs（界面语言为中文时为 logshare.cn），并生成一个链接。任何拿到该链接的人都可以查看日志内容。上传前，FCL 会隐藏日志中的游戏访问令牌，但日志仍可能包含第二节第 4 项所列的信息。
8. 陶瓦联机：只有在你开启多人联机，并在游戏内创建或加入房间时才会使用。FCL 会获取陶瓦联机节点列表，并通过 EasyTier 组建虚拟网络。联机期间，你的设备会与陶瓦联机节点、EasyTier 公共节点以及同一房间内其他玩家的设备交换网络地址等建立连接所需的信息；房间内的其他玩家可以看到你的玩家名。
9. 地区检测：FCL 仅根据设备的时区和系统地区判断设备是否可能位于中国大陆，例如用于优先选择较近的下载镜像。该判断完全在本机完成，FCL 不会因此查询你的 IP 地址或任何网络服务。
10. 游戏联网：游戏运行时会按游戏本身和模组的逻辑联网，例如连接你加入的服务器，这部分不受 FCL 控制。为了让游戏正常解析域名，FCL 会为游戏配置系统 DNS 和公共 DNS：系统语言为简体中文（中国）时使用阿里云公共 DNS 和 DNSPod，其他情况下使用 Cloudflare。游戏需要解析的域名会发送给这些 DNS 服务。
11. 外部链接与推广：文档、社区、赞助、MC 百科、网盘等链接只会在你点击后，由浏览器或对应的应用打开。设备地区为中国大陆且使用中文界面的用户，在启动游戏前可能偶尔看到夸克网盘的推广弹窗。FCL 不会因此向任何第三方提供你的信息。

四、权限

1. 存储：读写共享存储中的 FCL 文件夹，用于管理游戏文件、导入导出整合包和控制布局，以及保存日志。
2. 网络和网络状态：用于上述联网功能，以及在联网前检查网络是否可用。
3. 通知：显示下载进度、游戏运行状态和多人联机状态。
4. 前台服务：在后台继续下载、保持游戏进程运行，以及维持多人联机连接。
5. VPN：只在使用陶瓦联机时申请，用于建立联机所需的虚拟网络。FCL 不会利用该权限收集或修改其他应用的网络数据。
6. 麦克风：只有在你于启动器设置中主动申请后才会获得，供游戏内需要麦克风的功能使用，例如语音聊天类模组。
7. 安装和卸载应用：用于安装下载好的 FCL 更新，以及卸载 FCL 插件。
8. 查看已安装的应用：FCL 会在本机查找已安装的 FCL 插件，例如渲染器、驱动和 FFmpeg 插件。FCL 只读取识别插件所需的信息，不会上传应用列表。
9. 振动和防止休眠：用于触控按键的振动反馈，以及在下载和游戏期间防止设备休眠。

你可以随时在系统设置中撤销已授予的权限，但相关功能可能因此无法使用。

此外，在你于游戏中进行粘贴等操作时，游戏可能会读取剪贴板内容。FCL 只会把内容交给游戏，不会上传。FCL 不会读取 IMEI、Android ID、MAC 地址或广告标识符等设备标识符。

五、信息的存储与安全

1. 你的信息保存在你的设备上，由你决定保留多久。卸载 FCL 或在系统设置中清除 FCL 的数据，会删除应用私有目录中的数据；共享存储中的 FCL 文件夹需要你手动删除。
2. 请妥善保管你的设备。分享日志、整合包或游戏目录前，请检查其中是否包含你不希望公开的信息。

六、你的权利

1. 你可以在 FCL 中查看、修改和删除账户、皮肤、设置和游戏文件。
2. 你可以随时关闭多人联机等可选功能，并在系统设置中管理权限。
3. 你可以在“设置 > 关于 > 隐私政策”中撤回同意。撤回后 FCL 会立即退出，再次使用前需要重新同意。撤回同意不会自动删除你设备上的数据。
4. 对于第三方服务处理的信息，请按照对应服务的隐私政策行使你的权利。

七、未成年人

如果你是未成年人，请在监护人的陪同下阅读本政策，并在取得监护人同意后使用 FCL。

八、本政策的更新

本政策可能会随 FCL 功能的变化而更新。更新后，FCL 会在启动时展示新版本，并再次征求你的同意。

九、联系我们

如果你对本政策有任何疑问，请前往以下地址反馈：
https://github.com/FCL-Team/FoldCraftLauncher/issues

本政策提供多种语言版本。如不同语言版本之间存在差异，以简体中文版本为准。
