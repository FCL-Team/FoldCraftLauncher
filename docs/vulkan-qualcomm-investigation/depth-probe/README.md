# Off-screen depth-clear reproduction

This diagnostic can exercise a GPU-driver defect. **Save/close Minecraft
before running it**, since a device loss could interrupt other GPU clients.
It changes no game files/settings, driver binaries, system properties or
KGSL hook policy. No driver or Minecraft binaries are included.

Build the shaders using glslc:

```sh
glslc --target-env=vulkan1.3 depth.vert -o depth.vert.spv
glslc --target-env=vulkan1.3 depth.frag -o depth.frag.spv
```

Build `depth_probe.c` with an Android arm64 NDK compiler, Vulkan headers and
AOSP Android HAL headers (`hardware/hwvulkan.h`). Those headers are external
build dependencies, not generated by this test. Link `-ldl -lm`; use
`-Wl,-z,max-page-size=16384` on a 16-KiB-page Android device.

```text
depth-probe depth.vert.spv depth.frag.spv [width height rounds]
```

Default: 512 x 256, two rounds. Maximum dimensions: 4096 x 4096; maximum
rounds: 32. Every round compares five sequences documented in the parent
investigation. Every color/depth pixel is checked after a completed fence
wait; waits are limited to three seconds.

The Android path opens `/vendor/lib64/hw/vulkan.adreno.so`, using its HAL
entry points. Provide the required vendor library search paths for your
test environment. On the tested rooted tablet, the dependency search path
was `/vendor/lib64:/vendor/lib64/hw:/system/lib64` and the probe ran under
the game's UID/GID. This is not the game's exact app/SELinux namespace.

Remaining profiler-wrapped device commands are locally resolved to existing
core HAL exports, including submission. **Core symbol names are specific to
the inspected Qualcomm build**; missing exports cause an early setup failure.
Initial ENTRY lines show resolver results before the core replacements.
No installed binary is patched. Global kernel hooks are not bypassed.

Optionally set `FCL_PROBE_OUTPUT` to a writable PPM output file. The first
separate-clear result should be entirely green; red patches are rejected
hand fragments. This is synthetic output, not a Minecraft screenshot.

Exit 0: all pixels correct; exit 1: pixel mismatch; exit 2: setup/API/wait
failure. Process exit releases driver resources after completion. The probe
does not perform a potentially unbounded device-idle wait.

The host path uses the normal Vulkan loader and no Qualcomm-specific symbol
overrides. Reference-driver verification on a Linux system with Vulkan
headers, Mesa lavapipe and Khronos validation installed:

```sh
cc -Wall -Wextra -Werror -O2 depth_probe.c -ldl -lm -o depth-probe-host
VK_DRIVER_FILES=/usr/share/vulkan/icd.d/lvp_icd.json \
VK_INSTANCE_LAYERS=VK_LAYER_KHRONOS_validation \
VK_LAYER_VALIDATE_SYNC=1 \
./depth-probe-host depth.vert.spv depth.frag.spv 512 256 2
```

Host validation of this reproducer does not validate the whole Android game
or establish compatibility across Qualcomm driver versions.
